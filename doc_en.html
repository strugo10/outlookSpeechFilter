Outlook Speech Filter — Help and Sound Tutorial

Email Client Compatibility: Microsoft Outlook Classic (desktop versions 2013, 2016, 2019, 2021, and classic Microsoft 365 for Windows; not intended for the new web-based "New Outlook").

Official GitHub Repository: https://github.com/strugo10/outlookSpeechFilter

An add-on for the NVDA screen reader designed to mute repetitive, verbose email status announcements when navigating the message list in Microsoft Outlook Classic and optionally replace them with subtle audio cues (earcons).

Key Daily Productivity Benefits:
  • NVDA no longer reads lengthy prefixes ("unread, has attachment, replied, external..."), but immediately begins with the sender, subject, and date. The message status is instantly conveyed in the background by a brief earcon.
  • Sound order 100% matches the sequence of speech announcements (both when speech is unmuted and when querying current message statuses with a dedicated shortcut).
  • Streamlined Configuration: Individual sounds are managed in a dedicated dialog (Customize Event Sounds...), keeping the main NVDA settings panel fast and uncluttered.
  • 3-State Checkbox: The main sound toggle natively indicates "partially checked" when only a subset of sounds is enabled.
  • Share with Friends: Use "Share Add-on with Others..." to instantly copy download links or open a pre-filled recommendation email.
  • In mailboxes with grouping by flags or categories, it eliminates repetitive group prefixes and announces the flag color or category name first.
  • Bilingual Support: Automatically matches your NVDA and Windows language (Polish for Polish systems, English for all others) with manual override available.

How the Add-on Works

Muting Unwanted Speech Prefixes

By default, when moving with arrow keys through the Outlook message list, NVDA announces:

  • read/unread status (unread),
  • flag status (flagged),
  • attachments (has attachment),
  • inline images and screenshots in HTML email bodies,
  • replied or forwarded indicators (replied, forwarded),
  • importance (high importance, low importance),
  • meeting requests and calendar invites,
  • message categories,
  • external sender markers (external).

Outlook Speech Filter removes these repetitive prefixes so you immediately hear the sender, subject, and date, while subtle earcons keep you fully informed without speech fatigue.

Interactive Sound Tutorial (Earcons)

Earcons are brief, intuitive acoustic signals that convey vital status attributes in a fraction of a second. Below is the canonical list of all 11 event earcons with embedded HTML5 audio players:

# Event / Status Preview Sound Acoustic Characteristics Intuitive Association
1 Unread message Clear, high chime ping (880 Hz, A5) Traditional crystal desk chime for a new message.
2 Flagged message Short percussive click (1500 Hz) Pushpin pinned to a task board.
3 File attachment Snapping metallic paperclip Physical paper document attachment (PDF, DOCX, XLSX, ZIP).
4 Inline graphic / Screenshot Mechanical camera shutter click Visual photo or screenshot pasted inside the email text.
5 Replied Descending two-tone (660 Hz → 440 Hz) Return movement to sender ("reply sent back").
6 Forwarded Ascending three-tone (440 Hz → 660 Hz → 880 Hz) Forward movement ("passed on into the world").
7 High importance Two quick, sharp warning tones (1000 Hz) Urgent notification: "High priority item!".
8 Low importance Single gentle, low thud (280 Hz) Subdued, non-urgent information.
9 Meeting request Harmonic calendar bell chord (C5 with overtones) Calendar event or business appointment.
10 Category tag Vibrating percussive tone (700 Hz) Color folder label or tag.
11 External email Cautious low double tone Security alert: sender outside corporate organization.

Sound Themes

  1. Associative (Auditory Icons) — Default: Natural real-world sounds (paperclip snap, camera shutter, glass desk bell, pin click). Provides instant recognition without learning abstract tones.
  2. Minimalist (Electronic): Pure synthesized electronic sine wave tones.
  3. Instrumental (Acoustic / Percussion): Warm, organic acoustic instruments (marimba, vibraphone, chimes, woodblock).

Settings Guide

  1. Open the NVDA Menu (NVDA + N).
  2. Go to Preferences → Settings... (NVDA + Ctrl + G).
  3. Select Outlook - Speech Filter from the categories list.

Settings Structure

  • Language: Automatic, Polish, or English.
  • Mute unwanted message status announcements: Main speech filter toggle.
  • Enable conversation thread navigator: Toggles thread hierarchy window and quick jump gestures.
  • Play subtle earcons (3-state checkbox): Checked when all sounds are active, unchecked when none are, and partially checked when customized.
  • "Customize Event Sounds..." Button: Opens the dedicated sound customization dialog.
  • Sound Theme: Choice between Associative, Minimalist, and Instrumental.
  • Sound Volume Slider & "Test Volume" Button: Real-time volume preview.
  • Automatic Updates (GitHub): Automated update checks from official GitHub releases.
  • "Share Add-on with Others..." Button: Quick sharing dialog with download links and email draft.
  • "Contact Author (GitHub)..." Button: Direct route to submit issues on GitHub with diagnostic report copying.

Keyboard Shortcuts

Conversation Thread Navigator

  • NVDA + F7 or NVDA + Alt + F7 — Opens conversation thread navigator dialog with chronological list, search filter, and instant message jump.
  • Alt + K (in thread dialog) — Copies clean individual email body without reply history.
  • NVDA + Alt + Down Arrow — Jump to next (older) email in thread.
  • NVDA + Alt + Up Arrow — Jump to previous (newer) email in thread.
  • NVDA + Alt + Home — Jump to newest email at top of thread.
  • NVDA + Alt + End — Jump to oldest email starting the thread.

On-Demand Status Reporting

  • NVDA + Shift + Z — Speaks all status attributes of the current email, or summarizes multiple selected emails on demand.

Quick Toggles & Context Help

  • NVDA + Control + Shift + O — Quick toggle for speech muting.
  • NVDA + Control + Shift + S — Quick toggle for earcon sound playback.
  • NVDA + Control + Shift + T — Quick toggle for thread navigator.
  • NVDA + Control + Shift + H — Contextual help and shortcuts cheat sheet.
  • F1 — In-dialog contextual help.

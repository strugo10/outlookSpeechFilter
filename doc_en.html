Outlook Speech Filter — Help and Tutorial

Version: 1.16.4 (Build: 20261021.6)

Release date: October 21, 2026

Author: Sławomir Strugarek (with invaluable assistance from Antigravity AI — Google DeepMind)

Compatibility: NVDA 2021.1 – 2026.1+ | Microsoft Outlook 2013, 2016, 2019, 2021, Microsoft 365 (Classic desktop)

An add-on for the NVDA screen reader designed to mute repetitive, verbose email status announcements when navigating the message list in Microsoft Outlook (Classic version) and optionally replace them with subtle audio cues (earcons).

Key Benefits:
  • NVDA no longer reads lengthy prefixes ("unread, has attachment, replied, external..."), but immediately begins with the sender, subject, and date. The message status is instantly conveyed in the background by a brief earcon.
  • Sound order 100% matches the sequence of speech announcements (both when speech is unmuted and when querying current message statuses with a dedicated keyboard shortcut).
  • In views with grouping by flags or categories, it eliminates redundant system verbosity (such as "Group By: Collapsed: Categories: Orange category (Items: 125)...") and announces the category/flag name first (e.g., "Orange category, 125 items, collapsed").
  • Bilingual Support: Automatic language detection based on your NVDA and system settings (Polish for Polish systems, English for all other systems), with an explicit language switcher in settings.

Principles of Operation

Muting Verbose Speech Prefixes

By default in Microsoft Outlook, when navigating through messages with arrow keys, NVDA announces:

  • read/unread status (unread),
  • flag status (flagged),
  • presence of attachments (has attachment),
  • reply or forward status (replied, forwarded),
  • message priority (high importance, low importance),
  • calendar invitations (meeting request),
  • message categories,
  • external sender tag (external message).

This add-on mutes these lengthy verbal announcements, allowing NVDA to start speaking the sender, subject, and date immediately. You lose no context, because the muted details are instantly communicated by subtle audio earcons.

Earcon and Speech Order Consistency

The sequence of earcon playback strictly mirrors the order of verbal announcements (both when muting is off and when pressing the status query shortcut).

Intelligent Group Header Cleaning

In message views grouped by category or flag status, verbose repetitions such as:

"Group By: Collapsed: Categories: Orange category (Items: 125)..."

are cleaned up to announce the category name or flag color first (e.g., "Orange category, 125 items, collapsed").

Sound Table (10 Earcons)

The table below summarizes each sound cue in canonical playback sequence:

Order Status / Event Identifier Audio Characteristic Intuitive Association
1 Unread unread Pure high ping (880 Hz, A5) Classic new message chime.
2 Flagged flag Crisp percussive click (1500 Hz) Pinning / flagging marker.
3 File Attachment attachment Office paperclip snap (Associative theme) / Wooden marimba (Instrumental) / Single low plum (Minimalist) Traditional file attachment (PDF, Word, Excel, ZIP, etc.).
4 Inline Graphic / Screenshot inline_image Mechanical camera shutter click (Associative theme) / Vibraphone strike (Instrumental) / Double ascending tone (Minimalist) Graphic, screenshot or diagram embedded directly within the email body.
5 Replied replied Descending two-tone (660 Hz → 440 Hz) Return gesture to the sender ("sent back").
6 Forwarded forwarded Ascending three-tone (440 Hz → 660 Hz → 880 Hz) Outgoing gesture forwarding out into the world.
7 High Importance importance_high Rapid double sharp alert (1000 Hz) Urgent alarm: "Important message!".
8 Low Importance importance_low Soft low hum (280 Hz) Calm low-priority notification.
9 Meeting Request meeting Harmonic calendar chime (C5 chord with overtones) Calendar schedule / meeting reminder.
10 Category category Vibrating tone (700 Hz) Color category tag / label.
11 External Message external Brief double low tone Security alert for senders outside your organization.

Sound Themes

You can choose from 3 thoughtfully designed sound themes in the add-on settings:

  1. Associative / Auditory Icons (Default): Natural, real-world sounds with immediate intuitive meaning (metallic paperclip snap for file attachments, mechanical camera shutter for inline graphics, crystal chime for unread messages, pin tap for flags). Ideal for instant recognition without memorizing synthetic pitches.
  2. Minimalist (Electronic): Clean, synthesized electronic tones at precisely calibrated frequencies (single tone for file attachment, double ascending plum-plum for inline graphic).
  3. Instrumental (Acoustic Percussion): Warm, organic acoustic instruments and tuned percussion (wooden marimba for file attachment, metallic vibraphone bell strike for inline graphics, glass bell for unread, woodblock for flags).

Factory Defaults

Immediately after installation, the add-on is preconfigured with optimal defaults:

  • Sound playback: Enabled.
  • Mute unwanted speech: Enabled (you immediately hear the sender and subject).
  • Sound theme: Associative (default).
  • Sound volume: 80%.
  • Language: Automatic (matches your NVDA / system language).

Sounds Active by Default

  • Unread status
  • File attachment
  • Inline graphic / screenshot
  • High importance
  • Meeting request

Optional Sounds Inactive by Default

  • Message flag
  • Replied message
  • Forwarded message
  • Low importance
  • Message category
  • External message

Configuration in NVDA

To open the add-on settings:

  1. Open the NVDA Menu (NVDA + N).
  2. Navigate to: Preferences → Settings... (NVDA + Ctrl + G).
  3. In the categories list on the left, select: Outlook - Speech Filter (or Outlook - Filtr mowy (Outlook - Speech Filter) when set to Polish).

Language Selection

At the top of the panel, you can choose:

  • Automatic (match NVDA and system) — uses Polish if NVDA or Windows is set to Polish, and English for all other systems.
  • Polski (Polish) — forces Polish interface, announcements, and help.
  • English — forces English interface, announcements, and help.

Master Switches

  • Mute unwanted message status announcements in Outlook — mutes verbose speech prefixes on the message list.
  • Play subtle earcons instead of muted speech announcements — master switch for audio cue playback. When disabled, the sound options subpanel is collapsed.

Bulk Selection Buttons

  • Select all sounds — checks all 10 sound boxes. Becomes disabled when all sounds are already active.
  • Deselect all sounds — unchecks all 10 sound boxes. Becomes disabled when no sounds are selected.
  • Automatic Collapse and Restoration: Deselecting all sounds automatically turns off sound playback and collapses the subpanel, focusing the master checkbox. Re-checking the master switch instantly restores your previous sound selections!

Sound Checklist & Previews

Each event features its own checkbox and a dedicated sound preview button, which plays that specific earcon at full maximum volume (100%).

Volume Slider and Sequential Testing

  • Keyboard Navigation:
    • Up Arrow / Right Arrow — Increases volume by 1%.
    • Down Arrow / Left Arrow — Decreases volume by 1%.
    • Page Up — Increases volume by 10%.
    • Page Down — Decreases volume by 10%.
    • Home — 100% (maximum).
    • End — 0% (mute).
  • Real-Time Adjustment: Changes apply instantly. You can adjust the slider and immediately Alt + Tab into Outlook to check the sound level — without needing to click OK first!
  • "Test volume" Button: Sequentially plays all add-on sounds one after another at the slider's currently selected volume.

Utility and Contact Buttons

  • Contextual Help (F1)... — opens instant contextual help in NVDA's accessible browseable message buffer (ui.browseableMessage). The F1 key works throughout the settings panel and contact dialog.
  • Open Help and Sound Tutorial... — opens this complete documentation in your web browser in your chosen language.
  • Configure shortcut gestures... — opens NVDA's Input Gestures dialog with the add-on category pre-selected.
  • Contact add-on author... — opens an accessible dialog allowing you to copy the diagnostic report to your clipboard and open the 100% anonymous online feedback form (Google Forms). The form collects no email addresses or personal data (fully GDPR compliant).
  • Restore default settings... — safely resets all settings to factory defaults after confirmation.

Keyboard Shortcuts

Default shortcuts work reliably with both Insert and Caps Lock as the NVDA modifier key:

Email Conversation Thread Navigator

Intelligently detects individual emails within message discussion threads (in open inspector messages, reading pane, or message list):

  • NVDA + F7 or NVDA + Alt + F7 — Opens the conversation thread structure dialog (modeled on the standard NVDA Elements List). Displays a chronological list of all emails in the thread with sender name, date, and body snippet.
    • Includes real-time instant search filtering (type sender name or keyword).
    • Press Enter to jump caret directly to that email in Outlook reading window.
    • Press Alt + K to copy only the clean body of the selected email to clipboard (without quoted history).
    • Press F1 to view help for the thread dialog.
  • NVDA + Alt + Down Arrow — Jump to next (older) email in thread with audio and speech announcement.
  • NVDA + Alt + Up Arrow — Jump to previous (newer) email in thread.
  • NVDA + Alt + Home — Jump to newest email (top of thread).
  • NVDA + Alt + End — Jump to oldest email (first initial message).

On-Demand Status Announcement

  • NVDA + Shift + Z (or NVDA + Control + Shift + Z) — Speaks all statuses of the current message on demand. Identifies genuine attachments versus embedded email signature graphics, gives the exact count of attachments, announces replies, forwarded status, priority levels, and detects external messages. Announcements strictly match the sequence of earcons.
    Multiple messages selection support: When multiple messages are selected in the Outlook list (e.g. using Shift or Ctrl keys), pressing this shortcut announces a summary of the selected batch: total count of selected messages, unread count (or all read/unread), number of messages with attachments, flagged messages, and high priority messages.

Quick Toggle Switches

  • NVDA + Control + Shift + O — Quickly toggles speech muting on and off.
  • NVDA + Control + Shift + S — Quickly toggles sound cue playback on and off.

Contextual Help

  • NVDA + Control + Shift + H — Displays add-on contextual help and shortcuts reference in NVDA's browseable message buffer.
  • F1 — Contextual help in dialogs: pressing F1 in the settings panel or contact dialog immediately opens a quick reference and keyboard shortcuts list for that dialog.
